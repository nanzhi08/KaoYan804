2.4 课后习题
2.4.1  项目练习
一．练习目的
 1. 进一步掌握数据类型的分类及不同数据类型间的转换；
 2. 进一步熟悉常用的运算符和表达式的运算过程；
 3. 进一步练习运算符的优先经和结合性。
二．练习内容
 1.定义一个双精度类型的变量，分别将其转换为整型、长整型、单精度型输出。
 #include "stdio.h"
main()
{ double x=6.6;     
 printf("%d\n",(int)x);
  printf("%ld\n",(long)x);
   printf("%f\n",(float)x);
 getchar();
 }
 2.利用关系和逻辑表达式，分析闰年的计算方法。
#include "stdio.h"
main()
{int year;
 scanf("%d",&year);
 if((year%4==0&&year%100!=0)||(year%400==0))
   printf("%d年是闰年！",year);
   getch();
}
