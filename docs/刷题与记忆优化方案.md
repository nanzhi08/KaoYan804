# 刷题与记忆优化方案

## 已完成的前端优化

1. 学习仪表盘改为“今日学习指挥台”，把开始刷题、查看复习计划、定位薄弱章节放到首屏行动区。
2. 刷题页增加快捷模式：随机巩固、专注十题、记忆回捞，并修复快捷模式参数立即生效的问题。
3. 答题结果增加“复盘动作”，让用户在提交后马上完成答案核对、解析阅读和错因定位。
4. 复习计划页改为“今日记忆队列”，明确 1/3/5 分评分含义，并突出示例题回忆和复习间隔。
5. 学习统计页增加“薄弱点行动表”，按掌握度、考频、练习次数综合排序，帮助优先补高频低掌握知识点。

## 短期功能增加

1. 错因标签系统：为每次错题增加“概念不清、审题错误、边界条件、语法细节、算法步骤”等标签。
2. 错题二刷队列：错题不是只展示历史记录，而是自动进入 1 天、3 天、7 天的二刷队列。
3. 知识点闪卡：每个知识点生成“定义、易错点、典型题、口诀”四类卡片，支持快速自测。
4. 刷题后复盘页：一组题结束后集中展示正确率、耗时、错题、薄弱知识点和下一步建议。
5. 章节专项入口：从薄弱点行动表直接进入对应章节刷题，减少用户手动筛选成本。

## 中期优化方向

1. 自适应出题：根据掌握度、错题标签、考频权重动态调整题目抽取概率。
2. 间隔重复日历：按天展示未来复习压力，避免某一天堆积过多知识点。
3. 知识点-题目双向索引：在知识地图里直接看到关联题目、错题次数和最近一次作答结果。
4. AI 错因归纳：一组题完成后自动总结“本组最主要失分原因”和“下次刷题建议”。
5. 记忆稳定度指标：除掌握度外增加“遗忘风险”，用于判断哪些知识点需要提前复习。

## 长期能力建设

1. 个性化复习路径：系统每天生成“先复习、再刷题、最后复盘”的固定学习路线。
2. 考前冲刺模式：按真题考频和剩余天数生成高频专题训练计划。
3. 编程题判分增强：支持样例运行、边界用例提示和代码复杂度反馈。
4. 移动端离线复习：支持知识点闪卡、错题回顾、今日记忆队列离线可用。
5. 学习成效预测：根据最近正确率、复习完成率、薄弱点数量预测阶段性风险。

## 建议优先级

1. 第一优先级：错因标签、错题二刷队列、刷题后复盘页。
2. 第二优先级：章节专项入口、知识点闪卡、AI 错因归纳。
3. 第三优先级：自适应出题、复习日历、遗忘风险指标。

## 验证指标

1. 每日刷题数：判断刷题入口是否足够顺手。
2. 错题转正率：衡量错题复盘和二刷队列是否有效。
3. 复习完成率：衡量今日记忆队列是否真正被使用。
4. 高频知识点掌握度：衡量薄弱点行动表是否能拉动重点章节。
5. 遗忘回落率：衡量间隔重复是否降低知识点反复遗忘。
